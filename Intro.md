### What is Statistics?

Statistics is the art of learning from data. That art has four steps stitched together:
1. **Collecting** data
2. **Analyzing** data
3. **Presenting** data
4. **Drawing conclusions** from data

Course splits into two broad territories...

| Descriptive Statistics                                                                     | Inferential Statistics                                                                                |
| ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| Just _describing_ the data you have                                                        | _Using_ data to conclude something beyond the data                                                    |
| Frequency tables, graphs (bar/pie/histogram/stem-leaf), mean/median/mode, variance/std dev | Probability theory → permutations/combinations → random experiments → binomial & normal distributions |
| Here's what happened in my dataset                                                         | Here's what I can infer about the wider world from my dataset                                         |
Stats-1 is entirely the descriptive half plus the groundwork for inference (probability). The actual inference techniques come in Stats-2.

#### Module 1: Understanding & Describing Data 
- **Week 1** — Introduction to data: how data is collected, what is a _variable_ and an _observation_, classifying data as categorical (qualitative) vs numerical (quantitative)
- **Week 2** — Categorical data: frequency tables, choosing the right graphical technique (bar charts, pie charts), avoiding misleading graphs
- **Week 3** — Numerical data: measures of central tendency (mean, median, mode) and variation (range, variance, std. deviation), plus histograms & box plots
- **Week 4** — Association between two variables: contingency tables, scatter plots, relationship between categorical & numerical variables
#### Module 2: Probability 
- **Week 5** — Basic principles of counting: permutations and combinations
- **Week 6** — Introduction to probability: random experiments, simple events, compound events (needs set theory/set algebra as background)
- **Week 7** — Deeper probability concepts: mutually exclusive events, independent events

#### Module 3: Random Variables & Distributions 
- **Week 8** — Introduction to random variables (discrete random variables)
- **Week 9** — Expectation and variance of a random variable
- **Week 10** — Binomial distribution (Bernoulli experiments, applications)
- **Week 11** — Continuous random variables, probability density functions (intro)
- **Week 12** — Normal distribution and the empirical rule, applications

#### -->Variable vs Observation

- A variable is _a characteristic that is being recorded_ — it's a column in your dataset. 
- An observation is _one instance/record_ — it's a row.

#### Data Type

**1. Categorical (Qualitative) data** — values are categories/labels, not quantities.
**2. Numerical (Quantitative) data** — values are actual quantities you can do arithmetic on.

- Categorical data → frequency tables, bar charts, pie charts, proportions/counts.
- Numerical data → mean, median, variance, histograms, box plots.
